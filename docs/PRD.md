# 📄 CareerGPS 产品需求文档 (PRD)

> **版本**：v1.0 (MVP)  
> **文档状态**：已定稿  
> **面向对象**：Coding Agent (Cursor / Windsurf) & 开发者  

---

## 1. 📌 产品定位与目标

### 1.1 产品定位
**CareerGPS** 是一款专为大学生及初入职场人群打造的**一站式智能职业规划与求职护航平台**。通过“岗位可视化认知 + 精准自我探索 + 具备上下文记忆的生涯规划 Agent + 动态岗位排雷与简历优化 Agent”，打破求职市场的信息不对称，帮助用户实现“认知市场 ➜ 了解自我 ➜ 科学规划 ➜ 高效落地”的完整闭环。

### 1.2 MVP 核心目标
1. **全网 Release**：构建支持真实用户注册登录、支持多人并发访问的独立 Web 应用。
2. **核心双 Agent 爆破**：优先保证“生涯规划 Agent”与“岗位排雷/简历修改 Agent”的高可用性与动态路由能力。
3. **隐私与安全**：在提交大模型前实现简历及敏感数据的自动化隐私脱敏。
4. **极致性价比**：采用无服务器架构 (Serverless) 与高性价比国内大模型 API，控制运行与存储成本。

## 2. 👥 目标用户与痛点

* **目标用户**：高等院校本科生、专科生、研究生及 1-3 年初入职场新人。
* **核心痛点**：
  1. **市场认知盲区**：不了解岗位真实职责、学历硬门槛、内卷烈度与真实薪资成长空间。
  2. **自我探索缺失**：清楚 MBTI 但不懂如何转化为职场优势，缺乏对个人风险偏好与工作/生活平衡底线的认知。
  3. **路径规划迷茫**：确定方向后，不知道如何在大学各阶段（GPA、竞赛、实习、入党等）配置资源以实现效益最大化。
  4. **求职落地风险**：难以识别虚假招聘、皮包公司或岗位挂羊头卖狗肉；简历描述脱离 JD 核心要求，约面率低。

## 3. 🎯 MVP 功能模块与验收标准

### 模块一：用户体系与配额管理 (User & Quota System)
* **功能描述**：
  * 支持 **纯邮箱 + 验证码** 以及 **GitHub OAuth** 注册与登录。
  * 基于 Supabase Auth 实现安全会话管理。
  * 普通用户设置每日免费 Agent 对话与分析额度限制（如 10 次/天）。
* **验收标准**：
  * 用户输入邮箱可流畅收到验证码并完成注册登录。
  * 页面顶部显示用户登录状态及当日剩余额度。

### 模块二：岗位全景与思维导图 (Career Mindmap)
* **功能描述**：
  * 提供“市场化就业 vs 非市场化就业”树状职业全景导图。
  * **AI 实时联网搜索/生成**：用户点击特定细分岗位（如“AI产品经理”、“出海运营”）时，AI 实时生成/调取最新的岗位基本信息（薪资区间、学历要求、硬核技能、内卷烈度、发展路径）。
* **验收标准**：
  * 导图支持节点折叠/展开与流畅平移。
  * 点击末端节点能平滑弹出半屏岗位透视卡片。

### 模块三：自我探索与测评 (Self-Exploration & Assessment)
* **功能描述**：
  * **标准测评双轨制**：支持手动填空输入 MBTI / 霍兰德测试结果，并附带免费测试外链。
  * **自研精准测试（12 题）**：覆盖 4 个维度（风险与稳定性偏好、强度与生活平衡度、能力与天赋倾向、避坑与耐受底线），各 3 题。
  * **标签生成与同步**：测试完成后生成可视化标签卡片（如：`[实践派] [中度抗压] [拒绝形式主义]`），并**自动同步至用户数据库，作为后续 Agent 的前置上下文**。
* **验收标准**：
  * 用户可跳过测试直接手动填空输入已有结果。
  * 自研测试完成后能准确输出标签并存入数据库。

### 模块四：生涯规划 Agent (Career Planning Agent)
* **功能描述**：
  * 纯文本对话交互界面。
  * **持久化上下文记忆**：AI时刻读取并记住用户的年级、目标岗位及模块三的自研测评标签。
  * 针对大学各阶段（GPA、竞赛、实习、论文、学生组织等）提供效益最大化的规划建议。
* **验收标准**：
  * 跨会话/隔天重新打开聊天框时，Agent 仍能记住上文上下文与用户人设。

### 模块五：岗位排雷 / JD 拆解 / 简历修改 Agent (Job & Resume Agent)
* **功能描述**：
  * 支持文本输入及图片/文件（简历截图、JD 截图）上传。
  * **自动化隐私脱敏**：前端/后端在将简历提交大模型前，自动脱敏姓名、电话、身份证、邮箱等敏感词。
  * **动态路由分析（Dynamic Routing）**：
    1. **单上传 JD**：仅做 JD 核心素质提炼与面试考点预测，绝不凭空编造简历。
    2. **单上传简历**：做通用量化成果诊断与岗位反向推荐。
    3. **JD + 简历同时上传**：进行胜任力 Gap 匹配度打分与针对性 Markdown 简历改写建议。
  * **动态风险排查**：已知大厂/独角兽评估业务边缘度与加班压刀风险；初创/未知公司接入真实企业数据（天眼查/联网查询）排查资质与跑路风险。
* **验收标准**：
  * 传图/文件能精准解析文本并完成隐私脱敏。
  * 针对大厂和初创公司输出截然不同且符合常理的风险提示。

## 4. 🛑 绝对不做功能清单 (Out of Scope - 黑名单)

为了确保 10 天内顺利上线，MVP 阶段**坚决不做**以下功能：
1. ❌ **微信扫码/手机号验证码登录**（暂不增加国内繁琐认证开销）。
2. ❌ **PDF/Word 格式的修改后原样导出**（仅输出标准 Markdown 文本供用户复制）。
3. ❌ **复杂的大型社区/用户互动发帖功能**。
4. ❌ **人工一对一付费职业咨询服务**。

---

## 5. 🔒 隐私、安全与性能要求

1. **隐私脱敏**：用户简历数据提交至大模型前必须经过脱敏处理，且数据库存储用户文件需使用受保护的 Private Bucket。
2. **并发与响应**：全站采用 Next.js + Supabase 架构，支持至少 100 人同时在线对话与查询；大模型流式传输（Streaming）打字效果，首字响应时间 $< 2$ 秒。
3. **国内连通性**：静态资源配置 CDN 加速，API 采用国内硅基流动 / DeepSeek 直连节点，确保国内用户访问流畅无卡顿。
